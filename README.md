# LeetCode Solutions

This repository contains my solutions to the problems I solve on **LeetCode**, mainly written in **C++**.

LeetCode is part of my regular programming practice. I use it to sharpen my thinking and problem-solving skills by working through problems that require different approaches, techniques, and levels of reasoning.

## What I Practice

Through LeetCode, I practice:

* Data Structures & Algorithms
* Logical & Analytical Thinking
* Problem Solving
* Efficient Algorithm Design
* Breaking down complex problems into smaller parts
* Finding and comparing different approaches

Some of the topics I work with include:

* Arrays
* Strings
* Hash Tables
* Two Pointers
* Sliding Window
* Binary Search
* Linked Lists
* Stack & Queue
* Trees
* Graphs
* Recursion & Backtracking
* Dynamic Programming
* Greedy Algorithms
* Bit Manipulation
* Sorting
* Math

## Purpose

The purpose of this repository is to keep track of my LeetCode journey and the solutions I have worked on over time.

More importantly, I want the practice to improve the way I **think about problems, approach solutions, and write efficient code**.

## Note

These solutions reflect my learning process. Some solutions may change or be improved as I learn new techniques or discover better approaches.
